# 冷链物流 · 航班实时动态监控系统 —— 设计文档

> 版本：v1.0
> 日期：2026-10-20
> 项目地址：`flight-tracker/`
> 部署目标：GitHub Pages（纯前端静态站点）

---

## 一、项目概述

### 1.1 项目背景
公司是一家冷链物流企业，冷链货物大量依赖航空运输。目前缺少一个轻量工具来**按航班号或航司实时查询飞机的在空位置与运行状态**，用于运力监控、到货预警与途中的异常跟踪。

### 1.2 项目目标
- 输入**航班号**（如 `CCA1654`）或**航司**（如 `国航/CA/CCA`），在地图上实时显示所有匹配飞机的当前位置。
- 展示每架飞机的关键动态：**高度、速度、航向、垂直速率、经纬度**。
- 支持**自动刷新**（默认 10 秒），持续跟踪飞机移动轨迹，满足"实时动态监控"的核心诉求。
- 纯前端、零成本、可部署到 GitHub Pages，无需自建服务器。

### 1.3 名词约定
| 名词 | 含义 |
|------|------|
| callsign | 航班呼号，OpenSky 中为 ICAO 三字码+航班号（如 `CCA1654`） |
| ICAO 三字码 | 航司代码（如 CCA=国航、CSN=南航、CES=东航） |
| IATA 二字码 | 航司两字代码（如 CA、CZ、MU） |

## 二、需求分析

### 2.1 功能需求（按优先级）
| 优先级 | 需求 | 说明 |
|--------|------|------|
| P0 核心 | 按航班号查询 | 输入完整航班号精确匹配在空飞机 |
| P0 核心 | 按航司查询 | 输入 ICAO/IATA/中文/简称，返回该航司全部在空飞机 |
| P0 核心 | 地图实时展示 | Leaflet 地图标记飞机位置，飞行中/地面不同颜色 |
| P0 核心 | 航班详情 | 点选后展示高度/速度/航向/垂直速率/经纬度/更新时间 |
| P1 重要 | 自动刷新 | 每 10 秒重新抓取，跟踪轨迹 |
| P1 重要 | 航班清单 | 左侧列表展示所有匹配航班及其关键指标 |
| P2 可选 | 轨迹连线 | 连续位置点连线显示航迹（可后续扩展） |

### 2.2 非功能需求
- **性能**：单次抓取控制在合理体积（限定中国区域范围，避免全量）。
- **可用性**：响应式布局，PC 与手机均可用。
- **成本**：完全免费——数据源 OpenSky 免费接口 + OpenStreetMap 免费瓦片。
- **合规**：数据仅作监控参考，标注非实时管制数据。

### 2.3 用户画像
- **目标用户**：冷链物流公司的调运/监控人员。
- **使用场景**：查询某航班/某航司当前飞到哪里、是否延误/备降、何时可安排卸货。
- **痛点**：原有 god-eye-view 等项目过于重型（3D 地球、需自备服务器），不符合轻量监控需求。

## 三、技术架构

### 3.1 架构选型
| 层级 | 技术 | 理由 |
|------|------|------|
| 前端页面 | 原生 HTML + CSS + JavaScript | 零依赖构建、部署简单 |
| 地图库 | Leaflet 1.9.4 | 轻量（~42KB）、开源、GitHub Pages 可承载 |
| 底图瓦片 | OpenStreetMap | 免费开放、无需 API Key |
| 数据源 | OpenSky Network `states/all` | 免费实时航班数据，浏览器 CORS 可直接访问（已验证 HTTP 200） |
| 部署 | GitHub Pages | 静态托管、免费、公网可访问 |

### 3.2 为什么不用 god-eye-view 原项目
god-eye-view 是 **Cesium 3D 地球实时情报控制台**，包含飞机/船舶/卫星/地震/CCTV/语音控制等重型功能，需要 Node 24+、自定义 server 后端、需自备可运行 Docker/Node 的服务器，**GitHub Pages 无法承载**，且功能远超冷链物流"看航班轨迹"这一轻量诉求。因此**借鉴其数据源思路**（OpenSky），全新开发聚焦的轻量查询页。

### 3.3 数据流架构图
```
┌────────────┐   fetch(states/all?区域范围)   ┌─────────────────────┐
│  浏览器页面  │ ─────────────────────────────► │ OpenSky Network API  │
│ (Leaflet地图)│ ◄───────────────────────────── │  (免费实时航班数据)    │
└─────┬──────┘      JSON (states[])             └─────────────────────┘
      │ ①解析 callsign → 按航班号/航司过滤
      │ ②Leaflet label 定位经纬度
      │ ③每10秒自动刷新
      ▼
 地图标记 + 航班清单 + 详情浮层
```

## 四、功能模块设计

### 4.1 模块划分
```
flight-tracker/
├── index.html        # 页面骨架：查询区 + 地图区 + 列表区
├── css/style.css     # 暗色主题样式、响应式
└── js/
    ├── airlines.js   # 航司字典：ICAO/IATA/中文/简称 → 前缀映射
    └── app.js        # 核心：OpenSky查询、过滤、地图渲染、自动刷新、详情
```

### 4.2 核心模块说明
| 模块 | 职责 | 关键实现 |
|------|------|---------|
| `resolveAirlinePrefix()` | 把任意输入转成 ICAO 前缀 | 正则识别航班号/纯代码，字典匹配中文/英文/简称 |
| `fetchStates()` | 拉取 OpenSky 实时数据 | 限定中国区域范围，20s 超时，AbortController |
| `matchQuery()` | 过滤匹配航班 | 完整航班号精确匹配，否则前缀匹配 |
| `renderResults()` | 渲染地图标记 + 航班清单 | divIcon 标记，飞/地不同颜色 |
| `setupAutoRefresh()` | 定时刷新 | setInterval 10s，前端静默更新 |
| `showDetail()` | 详情浮层 | 展示全部动态指标 |

### 4.3 数据字段（OpenSky states 数组索引）
| 索引 | 字段 | 含义 |
|------|------|------|
| 0 | icao24 | 飞机注册号 |
| 1 | callsign | 航班呼号 |
| 2 | origin_country | 注册国 |
| 5/6 | lon/lat | 经纬度 |
| 7 | baro_altitude | 气压高度(ft) |
| 9 | velocity | 地速(kn) |
| 10 | true_track | 航向(°) |
| 11 | vertical_rate | 垂直速率 |
| 13 | geo_altitude | 几何高度 |

## 五、接口设计

### 5.1 数据源接口（外部）
**OpenSky Network states/all**
```
GET https://opensky-network.org/api/states/all?lamin=&lomin=&lamax=&lomax=
```
- 限中国区域范围：`lamin=0&lomin=70&lamax=55&lomax=145`
- 返回 JSON：`{ time, states: [[icao24, callsign, ...]] }`
- 浏览器 CORS 可访问，已验证 HTTP 200，约 8 千条（限范围后大幅减少）

### 5.2 应用内部接口（无后端）
本项目为纯前端，无自定义后端 API。查询交互全部在浏览器内完成。

## 六、部署方案

### 6.1 GitHub Pages 部署（已采用）
```
步骤：
1. 在 GitHub 创建仓库 flight-tracker
2. 上传 index.html、css/、js/ 等文件到 main 分支
3. Settings → Pages → Source: Deploy from a branch → main / root
4. 访问 https://<用户名>.github.io/<仓库名>/
```

### 6.2 本地运行
```
# 方式一：直接双击 index.html（注意部分浏览器对本地 fetch CORS 有限制，建议方式二）
# 方式二：本地起 http 服务
cd flight-tracker && python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 七、使用说明

1. 在左侧输入框输入航班号或航司，如 `CCA1654`、`国航`、`CA`、`CCA`、`MU`。
2. 点击「查询」或回车，地图与左侧列表即显示匹配航班。
3. 点击地图标记或列表卡片，弹出详情浮层查看完整动态。
4. 默认每 10 秒自动刷新，实时跟踪飞机位置移动。
5. 可取消勾选"自动刷新"停止轮询。

## 八、后续扩展建议（可选）
- **轨迹连线**：累计历史点位连线，直观展示航线。
- **冷链关联**：对接公司货单号，展示"航班→货单→温度记录"联动。
